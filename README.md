### 🚀 About me
 
I'm a computer science student with a soft spot for anything that combines **code and motorsport**. On one side I build cloud systems and backends, on the other I spend my free time chasing tenths of a second on iRacing, studying vehicle dynamics and fine-tuning my sim racing rig.
 
In **August 2026** I start my school-work internship, a step forward into the working world after months spent building real projects — not just classroom exercises.
 
### 🛠️ What I'm building
 
- **Tris Alternanza 2026** — a full-stack multiplayer web app (Next.js + AWS: API Gateway WebSocket, Lambda, DynamoDB, Cognito, CDK), the project that taught me the most this year: from debugging stubborn WebSocket connections to managing infrastructure as code
- **Telegram bot for Minecraft server management** — controlling an EC2 Spot instance via Telegram commands (`/goserver`, `/stopserver`), powered by a Node.js Lambda behind the scenes
- **Personal portfolio** — a Ferrari/motorsport-themed site with scroll-driven animations, to tell my story visually too
### 🏁 Off the code
 
When I'm not debugging, I'm probably on iRacing studying the competitive GT3 meta or working on my rig setup — because in the end, that's also about optimizing a system.
